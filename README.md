# COVID-19 Pakistan Folium Map

An interactive map of COVID-19 data across Pakistani cities, built with Folium in a Jupyter notebook.

## What it does

- Loads city-level COVID-19 figures (`cities-covid-19.xlsx`) and city coordinates (`coordinates-pk.xlsx`)
- Joins the two and plots each city on an interactive Folium map

## Tech stack

Python · Pandas · Folium · Jupyter

## Running

```bash
pip install pandas openpyxl folium jupyter
jupyter notebook Assign-2.ipynb
```
