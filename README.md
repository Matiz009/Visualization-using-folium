This project involved researching, compiling, and visualizing COVID-19 data for multiple cities in Pakistan. I collected and cleaned data from various public sources to create a reliable dataset. Using Python and Folium, I developed interactive maps to represent city-wise COVID-19 cases, enabling better understanding of regional trends and hotspots.

Key Tasks and Skills:

Researched and curated COVID-19 datasets from multiple sources to ensure accuracy.

Preprocessed data for visualization, handling inconsistencies and missing values.

Developed interactive maps using Folium to show city-level case distribution.

Analyzed trends and patterns to provide insights into regional spread.

Technologies / Tools: Python, Jupyter Notebook, Pandas, Folium

Outcome:
Created an interactive visualization tool that clearly represents city-wise COVID-19 data, showcasing skills in data research, cleaning, and geospatial visualization.
